# DCC folder consolidation - 2026-05-18

This archive keeps historical patch material out of the active app root.

Active source remains in the repository root, `assets/`, `build/`, `docs/`, and `scripts/`.

Archive groups:

- `apply-scripts/` - one-off patch applicator scripts from earlier rounds.
- `build-scripts/` - superseded helper batch files.
- `logs/` - historical build and drive-doctor logs.
- `patch-backups/` - hidden patch-backup directories moved from the root.
- `release-notes/` - older release reports and checklists.
- `root-snapshots/` - old root `.bak` and round snapshot files.
- `round-notes/` - historical round-by-round notes.
- `script-snapshots/` - old script backup files.
